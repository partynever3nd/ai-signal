# 观澜 AI SIGNAL

黑白编辑风格的 AI 资讯网站，包含本期 8 条经过官方原文核对的资讯。

## 内容

- 本期核验日期：2026-10-18（Asia/Shanghai）。
- 时间范围：2026-10-07 至 2026-10-16；百度条目为官方活动日程。
- 覆盖 OpenAI、Google、Microsoft、Anthropic、百度和腾讯。
- 搜索、机构筛选、时间线、浏览器本地收藏、来源核验记录与 Markdown 导出。
- 微博线索经官方原文对照后校正。知乎、微信公众号未取得本期可核验原文，未编造收录条目。

## 浏览与部署

直接打开 `index.html` 即可离线浏览。页面自带样式、脚本及本期数据，无外部字体或 CDN 依赖。原文链接需要联网。

GitHub Pages 可使用 `main` 分支的根目录发布；`.nojekyll` 禁用 Jekyll 处理。

## 文件

- `index.html`：与本地预览一致的完整网页。
- `news.json`：结构化资讯与核验记录。
- `AI_Briefing_2026-10-18.md`：完整文字简报。

这是一版本期资讯快照，未接入自动采集或定时更新。官方原文核对不等于对厂商性能宣传的独立验证；编辑观察明确标注为观点。

收藏保存在访问者自己的浏览器中，不上传服务器。
